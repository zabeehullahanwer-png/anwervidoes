# تحقیقی کام / Research workspace

یہ فولڈر `research-assistant` اسکل کا ورک اسپیس ہے (تفصیل: `.claude/skills/research-assistant/SKILL.md`)۔

| فولڈر | کیا ہے |
|---|---|
| `profile.md` | محقق کا تعارف (ڈگری، تھیسس، مہارت) |
| `pipeline.md` | تمام مقالات کی فہرست: خیال، مسودہ، ارسال، قبولیت |
| `thesis/` | ایم فل تھیسس (PDF/DOCX گٹ میں نہیں جاتے) |
| `articles/<slug>/` | ہر مقالے کا الگ فولڈر: plan, draft, refs, journal, log |
| `sources/` | پڑھے گئے مآخذ کے نوٹس |
| `phd/` | پی ایچ ڈی کا ریسرچ پروپوزل، SOP، CV |

تھیسس کی فائل `research/thesis/` میں رکھیں اور Claude سے کہیں: «تھیسس پڑھ لیں».
