# Citing Islamic primary sources

Verify every text against a real edition (print scan, Shamela with its printed-edition page match, or
quran.com / tanzil.net for the Quranic text). If not verified, mark `[تصدیق طلب]`.

## Quran

- Text: Uthmani script from tanzil.net or the Madinah mushaf; copy, never type from memory.
- Reference: surah name and number, ayah: *al-Baqarah 2:183* / سورۃ البقرۃ: 183.
- Translation: name the translator (Pickthall, Saheeh International, Abdel Haleem; Urdu: Maududi
  *Tafhim*, Taqi Usmani *Asan Tarjuma*, Fateh Muhammad Jalandhari) or say "author's translation".
- Usually not listed in the bibliography in Chicago; check the journal.

## Hadith

Give: collection, *kitab*, *bab* (if the style wants it), hadith number, edition, and grading.

> al-Bukhārī, *al-Jāmiʿ al-Ṣaḥīḥ*, Kitāb al-Īmān, Bāb ..., ḥadīth no. 1 (Beirut: Dār Ṭawq al-Najāh, 1422 AH).

Numbering differs by edition. Common choices: Bukhari (Dar Tawq al-Najah / Fath al-Bari numbering);
Muslim (Fuad Abd al-Baqi); Abu Dawud, Tirmidhi, Nasa'i, Ibn Majah (Dar al-Risalah / Shuayb al-Arna'ut or
the Abd al-Baqi / Albani numbering); Musnad Ahmad (Mu'assasat al-Risalah, al-Arna'ut). State the edition once
and keep it.

Grading: say whose (al-Tirmidhī: *ḥasan ṣaḥīḥ*; al-Albānī; Shuʿayb al-Arnaʾūṭ). For weak or fabricated
reports, say so; never present a *daʿīf* report as proof without noting it.

## Tafsir, fiqh, classical works

Cite author (death date AH/CE where the journal likes it), title, editor/muhaqqiq, publisher, city, year,
volume:page. Example:

> Ibn Kathīr (d. 774/1373), *Tafsīr al-Qurʾān al-ʿAẓīm*, ed. Sāmī Salāma (Riyadh: Dār Ṭayba, 1999), 2:45.

Urdu works: author, title, publisher, city, year, page (e.g., Mawlānā Mawdūdī, *Tafhīm al-Qurʾān*
(Lahore: Idārah-yi Tarjumān al-Qurʾān, ...), 1:120). Give the actual edition the user used.

## Transliteration

- English journals: **IJMES** (Islamic studies default) or **ALA-LC** (library standard, also for Urdu).
  Pick one per paper. Common names that have an English form (Quran, Hadith, Muhammad, Islam) may be
  left unmarked if the journal allows.
- Honorifics: ﷺ / (peace be upon him) per journal style; many English journals prefer none or "(PBUH)" once.
