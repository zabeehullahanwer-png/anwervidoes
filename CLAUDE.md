# anwervidoes

This repository serves one purpose: editing the **da'wah / deen videos** of the aalim
**Zabeehullah Leghari (ذبیح اللہ لغاری)**: dars-e-hadith, Quran, naseehat, seerat and masail.

- Use the `dai-video-editor` skill (`.claude/skills/dai-video-editor/SKILL.md`) for any video work.
  Brand details are in `dai-brand.json`, and the recording checklist is in `RECORDING-GUIDE.md`.
- Default output: a 9:16 reel for **Facebook Reels and TikTok**.
- Reply to the user in Urdu (Nastaliq script), respectfully.
- Quran and Hadith text and references must be exact. List anything unverified for the user to confirm.
- No instrumental music unless the user supplies it. Visuals stay aniconic (geometry, light, architecture).
- Never commit video files (`videos/` is git-ignored).
